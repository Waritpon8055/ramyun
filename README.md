# ระบบคิดเงินร้านรามยอน

เว็บคิดเงิน สรุปยอด สต็อก และสมาชิกสะสมแต้มของร้าน เป็นเว็บหน้าเดียว ไม่ต้อง build
ข้อมูลทั้งหมดเก็บใน Supabase และต้องล็อกอินด้วยบัญชีเจ้าของร้านก่อนใช้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวเว็บทั้งหมด |
| `config.js` | ค่าเชื่อมต่อ Supabase (ต้องแก้ก่อนใช้) |
| `assets/products/` | รูปซองสินค้า 10 ตัวแรก |
| `supabase/schema.sql` | สร้างตารางและสิทธิ์ในฐานข้อมูล |
| `supabase/seed.sql` | สินค้า ท็อปปิ้ง โปรโมชัน ชุดเดียวกับเว็บเดิม |

## ติดตั้งครั้งแรก

### 1. สร้างฐานข้อมูลใน Supabase

1. สมัครที่ supabase.com แล้วกด **New project** เลือก Region เป็น Singapore
2. ไปที่ **SQL Editor** วางเนื้อหา `supabase/schema.sql` ทั้งไฟล์ แล้วกด **Run**
3. วาง `supabase/seed.sql` แล้วกด **Run** เพื่อใส่สินค้าชุดเดิม
4. ไปที่ **Authentication > Users > Add user** สร้างบัญชีเจ้าของร้าน (อีเมล + รหัสผ่าน) และติ๊ก Auto Confirm
5. กลับไปที่ SQL Editor แล้วรันบรรทัดนี้ โดยแก้เป็นอีเมลที่เพิ่งสร้าง

   ```sql
   insert into public.shop_owners (email) values ('อีเมลเจ้าของร้าน');
   ```

6. ไปที่ **Authentication > Sign In / Providers** ปิด **Allow new users to sign up** เพื่อไม่ให้คนอื่นสมัครเองได้

### 2. ใส่ค่าเชื่อมต่อใน `config.js`

เปิด **Project Settings > API** ใน Supabase แล้วคัดลอกสองค่านี้มาใส่

- `supabaseUrl` ใช้ Project URL
- `supabaseAnonKey` ใช้ anon public key

anon key อยู่ในหน้าเว็บได้ตามปกติ คนที่ไม่ได้ล็อกอินด้วยอีเมลใน `shop_owners` จะอ่านหรือเขียนข้อมูลไม่ได้

### 3. เอาขึ้น GitHub

สร้าง repository แบบ **Private** บน GitHub แล้วรันในโฟลเดอร์นี้

```bash
git init
git add .
git commit -m "ระบบคิดเงินร้านรามยอน"
git branch -M main
git remote add origin https://github.com/<บัญชีของคุณ>/<ชื่อ-repo>.git
git push -u origin main
```

### 4. เปิดเว็บด้วย Vercel

1. ล็อกอิน vercel.com ด้วยบัญชี GitHub
2. กด **Add New > Project** แล้วเลือก repo นี้
3. Framework Preset เลือก **Other** ไม่ต้องตั้งค่าอื่น แล้วกด **Deploy**
4. จะได้ลิงก์แบบ `ชื่อ-repo.vercel.app` ส่งลิงก์นี้ให้ร้านได้เลย ต่อโดเมนของร้านทีหลังได้ใน Settings > Domains

## แก้เว็บหลังจากนี้

แก้ไฟล์แล้ว `git push` ขึ้น main Vercel จะอัปเดตเว็บให้เองภายในประมาณหนึ่งนาที
ร้านแค่รีเฟรชหน้า ไม่ต้องส่งลิงก์ใหม่ และข้อมูลใน Supabase ไม่หายเวลาแก้เว็บ

## ข้อควรรู้

- **เน็ตหลุดระหว่างขาย** หน้าจะขึ้นแถบแดงและลองบันทึกใหม่ให้เองเรื่อยๆ อย่าปิดหน้าจนกว่าแถบจะหายไป
- **หลายเครื่องพร้อมกัน** ข้อมูลซิงก์ถึงกันทันที แต่ถ้าสองเครื่องแก้สินค้าพร้อมกันในวินาทีเดียวกัน เครื่องที่บันทึกทีหลังจะทับ
- **สำรองข้อมูล** กดปุ่มสำรองข้อมูลในแท็บตั้งค่าเป็นระยะ จะได้ไฟล์ Excel มีสินค้า บิล และสมาชิก (ไม่รวมรูป)
- **แพ็กเกจฟรีของ Supabase** อาจพักโปรเจกต์ที่ไม่มีการใช้งานติดต่อกันหลายวัน ร้านที่ขายทุกวันไม่ค่อยเจอ ถ้าเจอให้กด Restore ในหน้าโปรเจกต์
- **ข้อมูลจากเว็บเดิม** `seed.sql` ย้ายมาเฉพาะสินค้า ท็อปปิ้ง โปรโมชัน และกติกาแต้ม บิลและสมาชิกบนเว็บเดิมเป็นข้อมูลทดสอบจึงไม่ได้ย้ายมา
